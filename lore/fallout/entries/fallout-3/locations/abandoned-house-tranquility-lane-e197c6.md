# Abandoned House (Tranquility Lane)

- type: location
- game: fallout-3
- variants: "Abandoned House", "Tranquility Lane buildings"
- categories: Tranquility Lane buildings

The Abandoned House is a house in the Tranquility Lane Simulation in Fallout 3. It contains a hidden terminal that allows the player character an alternate way to complete the Tranquility Lane quest.
