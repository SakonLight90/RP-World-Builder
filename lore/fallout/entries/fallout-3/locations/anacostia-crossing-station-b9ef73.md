# Anacostia Crossing Station

- type: location
- game: fallout-3
- variants: "Exterior D.C. Metropolitan Ruins", "Interior D.C. Metropolitan Ruins", "Red Line Metro Stations"
- categories: Fallout 3 locations; Exterior D.C. Metropolitan Ruins; Interior D.C. Metropolitan Ruins; Red Line Metro Stations

Anacostia Crossing Station is a Metro station and the southernmost point stop on the Red Line. According to a status monitor, this station is currently active. It is directly north of Rivet City.
