# Craterside Supply

- type: location
- game: fallout-3
- variants: "Megaton buildings", "Fallout 3 shops"
- categories: Fallout 3 locations; Megaton buildings; Fallout 3 shops

Craterside Supply is a store located in Megaton in Fallout 3. It can be found by going right and following the path as soon as the Lone Wanderer enters Megaton.
