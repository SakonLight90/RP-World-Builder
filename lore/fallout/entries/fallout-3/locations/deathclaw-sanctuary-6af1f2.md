# Deathclaw Sanctuary

- type: location
- game: fallout-3
- variants: "Northwest Territories"
- categories: Fallout 3 locations; Northwest Territories

## Summary from the source

The Deathclaw Sanctuary is a location in the Capital Wasteland in Fallout 3. It is located between Dickerson Tabernacle Chapel and Broadcast Tower KB5. It can be reached by traveling southwest from Fort Constantine, south from SatCom Array NW-05a, or east from SatCom Array NW-07c. It is home to numerous Deathclaws.
