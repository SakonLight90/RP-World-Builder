# Dry Sewers

- type: location
- game: fallout-3
- variants: "Interior D.C. Metropolitan Ruins", "Fallout 3 Metro Tunnels"
- categories: Fallout 3 locations; Interior D.C. Metropolitan Ruins; Fallout 3 Metro Tunnels

The Dry Sewers is a sewer system that can be reached from Dupont Circle. It is one path to Our Lady of Hope Hospital in the Reilly's Rangers quest.
