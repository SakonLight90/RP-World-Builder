# Dupont Circle Station

- type: location
- game: fallout-3
- variants: "Interior D.C. Metropolitan Ruins", "Red Line Metro Stations"
- categories: Fallout 3 locations; Interior D.C. Metropolitan Ruins; Red Line Metro Stations

Dupont Circle Station is a pre-War Red Line Metro station. It is mostly collapsed, and a Raider-infested area in it has to be crossed to reach Metro Central.
