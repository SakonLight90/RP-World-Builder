# Federalist Lounge

- type: location
- game: fallout-3
- variants: "Fallout 3 shops", "Tenpenny Tower"
- categories: Fallout 3 locations; Fallout 3 shops; Tenpenny Tower

The Federalist Lounge is a lively tavern on the first floor of the Tenpenny Tower run by Shakes, a bartending Protectron.
Unlike other shops, the Federalist Lounge is always open. Should Shakes be killed during the ghoul takeover, no one will run the Federalist Lounge.
