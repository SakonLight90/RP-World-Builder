# Franklin Metro Utility

- type: location
- game: fallout-3
- variants: "Blue Line Metro Stations"
- categories: Fallout 3 locations; Blue Line Metro Stations

## Summary from the source

Franklin Metro Utility is a metro utility tunnel and part of the metro network in the Capital Wasteland in Fallout 3. It is slightly irradiated, heavily so in some places, and partially water-filled. It has exits to Falls Church and Hubris Comics.
