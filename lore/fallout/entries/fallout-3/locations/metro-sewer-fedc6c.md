# Metro Sewer

- type: location
- game: fallout-3
- variants: "Fallout 3 Metro Tunnels"
- categories: Fallout 3 locations; Fallout 3 Metro Tunnels

## Summary from the source

The Metro Sewer is an underground link between Pennsylvania Avenue and Seward Square. It is part of the metro system under the Capital Wasteland, but the end points have fallen in and it can only be accessed from sewer grates.
