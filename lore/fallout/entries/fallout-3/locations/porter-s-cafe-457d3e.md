# Porter's Café

- type: location
- game: fallout-3
- variants: "Canterbury Commons", "Fallout 3 shops"
- categories: Fallout 3 locations; Canterbury Commons; Fallout 3 shops

Porter's Café is a shop in Canterbury Commons, run by Joe Porter. It is located in an old Dot's Diner, across from Ernest "Uncle" Roe's House, in the center of the town.
