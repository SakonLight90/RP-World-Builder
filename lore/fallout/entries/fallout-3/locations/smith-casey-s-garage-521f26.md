# Smith Casey's Garage

- type: location
- game: fallout-3
- variants: "Southwest Territories"
- categories: Fallout 3 locations; Southwest Territories

## Summary from the source

Smith Casey's Garage is an abandoned automotive service garage in the Capital Wasteland in Fallout 3. It also houses the entrance to Vault 112, which is accessible through a door in the floor of the main garage area.
