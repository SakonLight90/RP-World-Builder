# Sunken Sewer

- type: location
- game: fallout-3
- variants: "Interior D.C. Metropolitan Ruins", "Fallout 3 Metro Tunnels"
- categories: Fallout 3 locations; Interior D.C. Metropolitan Ruins; Fallout 3 Metro Tunnels

## Summary from the source

The Sunken Sewer is a small irradiated underground location, containing some Feral Ghouls and possibly a Glowing One or Feral Ghoul Reaver (with the Broken Steel add-on). It can be reached from the northern part of Dupont Circle.
