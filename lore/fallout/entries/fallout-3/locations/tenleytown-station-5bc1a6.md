# Tenleytown Station

- type: location
- game: fallout-3
- variants: "Interior D.C. Metropolitan Ruins", "Red Line Metro Stations"
- categories: Interior D.C. Metropolitan Ruins; Red Line Metro Stations

## Summary from the source

Tenleytown Station is a Red Line Metro tunnel that connects to Friendship Station. It must be traversed to get to the Galaxy News Radio station through the Chevy Chase North exit in the south.
