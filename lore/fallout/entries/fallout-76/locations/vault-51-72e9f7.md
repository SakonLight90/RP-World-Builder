# Vault 51

- type: location
- game: fallout-76
- categories: Fallout 76 locations; Vault 51

## Summary from the source

Vault 51 is a Vault-Tec Vault located in The Forest region of Appalachia. It was the focal point of the Nuclear Winter game mode in Fallout 76 until its discontinuation on September 8, 2021. The location is open for exploration in all game modes as of the release of Fallout Worlds.
