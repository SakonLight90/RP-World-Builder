# Destroyed Freeway Bridge

- type: location
- game: new-vegas
- variants: "Fallout: New Vegas Roadways", "Fallout: New Vegas Bridges"
- categories: Fallout: New Vegas unmarked locations; Fallout: New Vegas Roadways; Fallout: New Vegas Bridges
